# MathStudio

**MathStudio** is a professional Mathematics Authoring and Examination System designed for teachers, students, researchers, publishers, and examination bodies.

## Features

- Professional Equation Editor
- Mathematics Symbol Library
- Formula Builder
- Graph Studio
- Geometry Studio
- Examination Builder
- Word & PDF Export
- Native `.mst` Project Format

## Technology Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Desktop
- Electron

### Backend
- FastAPI (Python)

### Database
- SQLite
